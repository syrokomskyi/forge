# Contributing to @warpgogol/forge

Forge is developed in the [warpgogol/werkstatt](https://github.com/syrokomskyi/werkstatt) monorepo. The standalone [syrokomskyi/forge](https://github.com/syrokomskyi/forge) repo is auto-generated by `repo-extract` — do not open PRs there.

## Development setup

```sh
git clone https://github.com/syrokomskyi/werkstatt.git
cd werkstatt
pnpm install
```

## Project structure

- `packages/forge/src/` — portable core (no `@warpgogol/*` imports)
- `packages/forge/os/` — ForgeModule registrations and command handlers
- `packages/forge/bin/` — CLI entrypoint
- `packages/forge/skills/` — skill definitions
- `packages/forge/profiles/` — stack profiles

## Making changes

1. Create an RFC for architectural changes (`forge rfc.create`)
2. Implement the change
3. Add or update tests
4. Run `pnpm exec forge doctor` and `pnpm exec forge rfc.validate`
5. Run `pnpm run build:check` for type checking
6. Commit via `ecosystem.commit`

## Publishing

Publishing is automated via `repo-extract` + GitHub Actions CI. See [docs/maintainers/publishing.md](docs/maintainers/publishing.md).
