# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in `@warpgogol/forge`, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Email security@warpgogol.com with a description of the vulnerability and steps to reproduce.
3. You will receive a response within 48 hours.

## Scope

Security issues in the Forge CLI, skill definitions, validators, or publishing pipeline are in scope. Security issues in projects that use Forge are out of scope — report those to the respective project maintainers.

## Disclosure

We follow responsible disclosure. Once a fix is released, we will publish a GitHub Security Advisory with credit to the reporter (unless they prefer to remain anonymous).
